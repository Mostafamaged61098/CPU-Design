# CPU-Design
<br/>A CPU Design Using Logisim
<br/>using main logic Gates to build a 32 bit CPU 

<br/><br/>In order to view or edit this files, you will need to download and install Logisim from one of the following links depending on your OS: 

<br/>Windows: https://github.com/logisim-evolution/logisim-evolution/releases/download/v3.9.0/logisim-evolution-3.9.0-x86_64.msi
<br/>Ubunutu: https://github.com/logisim-evolution/logisim-evolution/releases/download/v3.9.0/logisim-evolution_3.9.0_amd64.ubuntu22.04.deb
<br/>RedHat: https://github.com/logisim-evolution/logisim-evolution/releases/download/v3.9.0/logisim-evolution-3.9.0-1.x86_64.rpm

### Note:
in order for the Design to work propably, please install Logisim Version 3.9 or older, as newer version cause some errors that will be fixed later

## Usage
you can check for the Opcodes in the 2 excel sheets in the Repo, then you can write the required opcodes in each RAM cell, and Run the clock so that the CPU starts fetching Decoding and Executing each instruction you added in the RAM
